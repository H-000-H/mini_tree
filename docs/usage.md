## 1. 术语说明 / 1. Terminology

| 术语 / Term | 含义 / Meaning | 主要落点 / Main Location |
| :--- | :--- | :--- |
| **DTS / DTSI** | Linux 风格设备树源文件 / Linux-style device tree source files | 平台 `board/dts`、`board/dtsi`；中间件默认占位 `board/dts/board.dts` |
| **dtc-lite** | 编译期设备树编译器 / Compile-time device tree compiler | `tools/dtc-lite.py`、`tools/dtc_lite/` |
| **dt-bindings** | 仅 `#define` 的共享常量 / Shared `#define`-only constants | `board/dt-bindings/` |
| **DRIVER_REGISTER** | 驱动注册宏 → 静态 probe/remove 符号 / Driver registration macro → static probe/remove symbols | `board/include/driver.h` |
| **probe 表** | dtc-lite 生成的函数指针表 / Function-pointer table generated by dtc-lite | `board_probe.c` / `board_devtable.*` |
| **HAL weak** | 中间件空实现，平台强符号覆盖 / Middleware weak empty implementations overridden by platform strong symbols | `hal/*/*.c` |
| **硬件直投** | DTSI 宏值进入配置结构体，HAL 零翻译 / DTSI macro values feed the config structs with zero HAL translation | HAL 头字段注释 / comments in HAL header fields |
| **Bus poison** | 未定义 `*_BUS_IMPL` 时禁止调 `hal_*` / Calling `hal_*` is poisoned unless `*_BUS_IMPL` is defined | `bus/*/*_bus.h` |
| **VFS（本仓库 / this repo）** | 设备 `file_operations` 层，**不是** Linux 内核 VFS / Device `file_operations` layer, **not** the Linux kernel VFS | `vfs/*` |
| **OSAL** | 操作系统抽象三后端：裸机协作 / FreeRTOS v11.3.0 / RT-Thread v5.3.0 / OS abstraction with three backends: bare-metal cooperative / FreeRTOS v11.3.0 / RT-Thread v5.3.0 | `osal/` |
| **VIRQ** | 虚拟中断号 + 上/下半部 / Virtual IRQ numbers + top/bottom halves | `interrupt/` |
| **status / VFS_ERR_*** | 统一错误码 / Unified error codes | `core/include/status.h` |
| **积木 / Brick** | 可选开源能力块（GUI/网络/FS…）/ Optional open-source capability blocks (GUI/network/FS…) | [ecosystem.md](ecosystem.md)；`mini_tree_link_*` |
| **vendor / Fetch** | 仅 FreeRTOS / RT-Thread / ETL 常驻 `lib/`；全部积木（含 TinyUSB / lwIP / cJSON）链接期 FetchContent / Only FreeRTOS / RT-Thread / ETL stay in `lib/`; all bricks (incl. TinyUSB / lwIP / cJSON) use link-time FetchContent | [ecosystem.md](ecosystem.md) §0 |
| **两段式点火 / Two-phase ignition** | pre-os → start-tasks → complete → 调度 / pre-os → start-tasks → complete → scheduling | `system_init.h` / `system_init.hpp` |

## 5. 最小心智模型 / 5. Minimal Mental Model

一次完整 I/O 的数据流 / Data flow of one complete I/O operation:

```text
业务 device_ioctl(dev, cmd, …)
  → board 持锁检查状态
  → vfs 驱动 fops
  → bus_*（若该外设有 bus）
  → hal_*（平台强符号）
  → 寄存器 / SDK
```

一次启动的两段式点火 / Two-phase ignition of one boot:

```text
mini_tree_pre_os_init()
  → （业务/平台可选准备）
mini_tree_start_tasks()      // 含 board_driver_probe_all
system_init_complete()
  → vTaskStartScheduler / rt_system_scheduler_start / mini_tree_system_loop（裸机）
```
