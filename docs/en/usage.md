## 1. Terminology

| Term | Meaning | Main Location |
| :--- | :--- | :--- |
| **DTS / DTSI** | Linux-style device-tree source files | platform `board/dts`, `board/dtsi`; middleware's default placeholder `board/dts/board.dts` |
| **dtc-lite** | compile-time device-tree compiler | `tools/dtc-lite.py`, `tools/dtc_lite/` |
| **dt-bindings** | shared constants, `#define` only | `board/dt-bindings/` |
| **DRIVER_REGISTER** | driver-registration macro → static probe/remove symbols | `board/include/driver.h` |
| **probe table** | function-pointer table generated by dtc-lite | `board_probe.c` / `board_devtable.*` |
| **HAL weak** | middleware's empty implementation, overridden by platform strong symbols | `hal/*/*.c` |
| **HW pass-through** | DTSI macro values enter the config struct; HAL does zero translation | HAL header field comments |
| **Bus poison** | calling `hal_*` is forbidden until `*_BUS_IMPL` is defined | `bus/*/*_bus.h` |
| **VFS (this repo)** | the device `file_operations` layer — **not** the Linux-kernel VFS | `vfs/*` |
| **OSAL** | OS abstraction, three backends: bare-metal (cooperative / preemptive) / FreeRTOS v11.3.0 / RT-Thread v5.3.0 | `osal/` |
| **VIRQ** | virtual IRQ number + top/bottom halves | `interrupt/` |
| **status / VFS_ERR_*** | unified error codes | `core/include/status.h` |
| **Brick** | optional open-source capability block (GUI/network/FS…) | [ecosystem.md](ecosystem.md); `mini_tree_link_*` |
| **vendor / Fetch** | only FreeRTOS / RT-Thread / ETL live permanently in `lib/`; TinyUSB / lwIP / cJSON are config-time FetchContent, the rest link-time | [ecosystem.md](ecosystem.md) §0 |
| **two-phase ignition** | pre-os → start-tasks → complete → scheduler | `system_init.h` / `system_init.hpp` |

## 3. What's in the Repo

| Area | Role | Vendor SDK? |
| :--- | :--- | :---: |
| `docs/` | topic docs (entry: [README.md](README.md)) | No |

## 5. Minimal Mental Model

One full I/O data flow:

```text
business device_ioctl(dev, cmd, …)
  → board holds lock & checks state
  → vfs driver fops
  → bus_* (if the peripheral has a bus)
  → hal_* (platform strong symbol)
  → register / SDK
```

One two-phase ignition:

```text
mini_tree_pre_os_init()
  → (business/platform optional prep)
mini_tree_start_tasks()      // includes board_driver_probe_all
system_init_complete()
  → vTaskStartScheduler / rt_system_scheduler_start / mini_tree_system_loop (bare-metal)
```
