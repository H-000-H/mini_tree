# mini-os

`mini-os` is the kernel of the **mini-tree** project: a **minimal real-time operating system (RTOS)** for Cortex-M microcontrollers. It provides a small, configurable set of RTOS primitives and runs standalone in bare-metal environments with **no dependency on the C library** (freestanding).

## Features

- **Scheduler**
  - Priority-based preemptive scheduling with 32 priority levels
  - Round-robin time slicing among equal-priority threads (optional, off by default)
  - Ready bitmap (`g_priority` 32-bit group + `CTZ`) for O(1) highest-priority selection
  - Layered tick wheel driving thread delays and sync timeouts (`MINI_OS_TICK_WHEEL`, power of two)

- **Thread**
  - Dynamic / static creation, dynamic deletion
  - Suspend / resume, dynamic priority change (with mutex priority-inheritance roll-back)
  - `yield`, multiple delay forms (ticks / milliseconds / absolute tick)
  - Exit cleanup callback, user data
  - Dedicated idle thread and idle hook
  - detach / join (optional, off by default; the two are bound to the same switch)

- **Synchronization**
  - Semaphore: counting / binary, mutually convertible
  - Mutex: recursion (optional), priority inheritance with chained propagation (depth limited by `MINI_OS_MUTEX_PI_CHAIN_MAX`), wake-on-delete
  - Event group (optional, off by default): 32-bit flags, OR / WHOLE wait semantics, configurable auto-clear

- **Communication**
  - Queue: fixed-size message FIFO, blocking send / receive, ISR-safe variants

- **Timer**
  - Hard timers (callback in tick / ISR context) and soft timers (callback in a dedicated service thread)
  - One-shot / periodic (fixed frequency)
  - Independent timer tick wheel, decoupled from the scheduler thread wheel

- **Memory management**
  - `malloc/free` model: first-fit + split + adjacent free-block coalescing
  - Optional slab allocator (paged from the heap, or an independent static slab region)
  - Heap taken from the linker script (`__heap_start` / `__heap_end`)

- **Time and critical sections**
  - 64-bit tick counter (optional, off by default, via an overflow counter)
  - Critical sections via PRIMASK full mask, or BASEPRI threshold (only masking IRQs not higher than `MINI_OS_IRQ_MAX_SYSCALL_PRIORITY`)

- **Portable layer (arch)**
  - Cortex-M0 / M0+ / M3 / M4 / M7
  - Optional FPU lazy save, stack overflow check
  - PendSV context switch, SVC callback dispatch

- **Engineering traits**
  - No libc dependency; uses freestanding headers such as `stddef.h`
  - C11 `_Generic` atomic fallback, with both GCC and Clang builtin paths

## Build

Requires `arm-none-eabi-gcc` (or a compatible toolchain) and `ninja`.

```sh
cmake --preset Debug
cmake --build --preset Debug
```

Optional `Release` configuration. Output is the static library `libmini-os.a`.

> Note: the kernel uses GNU extensions (e.g. `__attribute__((constructor))`), so Keil (ARMCC) cannot use it directly; target GCC / Clang toolchains.

## Configuration (three-tier priority)

Each option is resolved in the same order, so it can hook into kconfig, be customized externally, and always has a safe default:

1. `CONFIG_<NAME>` —— generated by mini-tree's kconfig system (`config.h`)
2. `MINI_OS_<NAME>` —— predefined by an external build system (command-line `-D` or a parent project); the value is kept as-is
3. Built-in default —— provided by the kernel itself

Feature switches are always defined as `1` or `0`, so always test with `#if`, never `#ifdef` (`#ifdef` would be true for a disabled option as well).

Optional features (off by default): event group `MINI_OS_EVENT`, find-by-name `MINI_OS_FIND_BY_NAME`, detach/join `MINI_OS_THREAD_DETACH`, spinlock `MINI_OS_SPINLOCK`, 64-bit tick `MINI_OS_LONG_TIME`, time slice `MINI_OS_TIME_SLICE`, FPU `MINI_OS_USE_FPU`, stack overflow check `MINI_OS_STACK_OVERFLOW_CHECK`.
